# Shtark Link — корпоративный мессенджер на Supabase

## Состав
- Корень репозитория — сайт (публикуется через GitHub Pages).
  - `config.js` — адрес проекта Supabase и публичный ключ.
  - `app.js` — логика приложения, `index.html` — интерфейс, `sw.js` — push-уведомления.
  - `vendor/` — библиотеки supabase-js и livekit-client (лежат локально, интернет-CDN не нужен).
- `supabase/migrations/` — схема базы (таблицы `sl_*`, правила доступа, функции). Уже применена в проекте «night-fare».
- `supabase/functions/` — серверные функции (уже развёрнуты):
  - `sl-register` — регистрация по коду приглашения;
  - `sl-admin` — кабинет администратора (добавить, отключить, вернуть доступ, сбросить пароль, права админа);
  - `sl-push` — push-уведомления;
  - `sl-call-token` — пропуск в звонок LiveKit.

## Что умеет
Каналы, личные и групповые чаты, файлы до 50 МБ, календарь дел, задачи со сроками и комментариями,
push-уведомления, голосовые и видеозвонки 1-на-1 и конференции (LiveKit), кабинет администратора.

## Безопасность
- Все данные защищены правилами доступа (RLS) на уровне базы: личные чаты видят только двое,
  групповые — только участники, файлы — только участники чата.
- Отключённый сотрудник сразу теряет доступ, его история сохраняется.
- Регистрация — только по коду приглашения (администратор может её выключить).

## Настройка звонков
Нужны секреты функций в Supabase (Edge Functions → Secrets): `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`
из проекта LiveKit Cloud (cloud.livekit.io) или своего сервера LiveKit.
